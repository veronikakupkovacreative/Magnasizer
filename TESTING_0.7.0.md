- Open Demo Project.
- Verify the demo master uses the updated editorial layout.
- Verify the headline reads `BETTER.` on line 1 and `BY` on line 2.

## Brand kit
- Open the right properties panel.
- Confirm a new `Brand kit` section appears.
- Select a text layer and click a swatch.
- Verify the layer fill color updates.
- Select a shape layer and click a swatch.
- Verify the shape fill color updates.
- Deselect all layers and click a swatch.
- Verify the artboard background updates.

## Smart Resize composition
- Generate multiple presets in balanced mode.
- Re-run generation in product mode.
- Verify product-led layouts give the bottle more visual space.
- Re-run generation in text mode.
- Verify copy-led layouts give the headline more room.
- Verify portrait/story outputs keep the CTA and copy usable.
- Verify compact outputs remain readable.

## Existing protected variants
- Manually edit one generated resize.
- Generate again with different presets or composition.
- Verify the customized resize stays untouched.
